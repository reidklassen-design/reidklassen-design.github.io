Reid completes every identity, verification, agreement, payment, and publish
step. Use real information, enable two-factor authentication where available,
and store credentials only in Reid's password manager. Never put identity
documents, addresses, account recovery data, or payment details in this repo.

- [ ] Headline: “Custom phone apps, desktop apps, and MCU firmware.”
- [ ] Portfolio URL uses the channel source code.

      accurate descriptions; SecurityCam is labelled coming soon.

      supports them.
